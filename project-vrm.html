Management System

VRM

A digital management system designed to streamline election-related registration, distribution activities, and administrative operations through a mobile application and centralised dashboard.

Project cover image
Role

UI/UX Designer

Platform

Mobile app + dashboard

Tools

Figma, Prototyping

Year

2026

Overview

VRM brings election-related registration, distribution activities and administrative work into a single system, with a mobile application for the field and a central dashboard for oversight.

The Challenge

Administrative work spread across several tools makes it hard to see what has been registered, distributed and confirmed. The system needed one source of truth that both field teams and administrators could rely on.

Approach

I designed the information structure first — the people, materials and records involved — then built the mobile and dashboard experiences around the same data so each screen tells a consistent story.
